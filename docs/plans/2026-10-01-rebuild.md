## 本階段依賴的不變量

| 不變量 | 預計依賴模組；落地後補實際路徑 |
|---|---|
| 業務判定由 FastAPI 統一執行 | auth、quota、payments；Next.js 僅消費契約 |
| 任一 AI 入口都須認證與成本控制 | summarize、chat、mindmap、quota |
| SSE 不被緩衝，done/error 為唯一終態 | stream protocol、前端 parser、同源 proxy |
| 外部與模型輸出皆為不可信資料 | URL policy、Markdown renderer、SVG export |
| 支付與額度併發重送只生效一次 | payment fulfillment、quota reservation、transaction |
| key 不進瀏覽器；session token 僅存 HttpOnly cookie，不進 JS／JSON／日誌 | config、auth、logging、CI |

  - B 原作方案：摘要每日 3 次、VIP 不限；仍需決定 chat/mindmap 計次，費用不易預估。
  - 建議請求先預留，成功結算、失敗釋放；取消若已花費是否扣次、影片長度／token／日預算門檻需拍板，不寫死數字。request id 建議由 client 產生 UUID，同 user+operation+id 對相同 payload dedup、不同 payload 回 409；dedup 保留期限需隨重試窗口拍板。
- **D4 支付權益**（未決；擋 P6；不需 spike）
  - A 單次購買一個月期限，不自動續訂：符合原作，較簡單（建議）。
  - B 自動續訂：需 subscription、續款失敗、取消與權益同步，範圍更大。
